# JMComic 黑名单设计规格

## 目标

为 JMComic 下载增加本子 ID 黑名单和作者名称黑名单。两类黑名单分别配置启用状态和数组内容，互不依赖。命中任一黑名单时，插件在创建下载缓存或调用下载命令前停止任务，并向用户明确说明原因。

作者名称黑名单复用 JMComic 官方包随 `jmcomic` 一同安装的 `jmv` 命令，不新增 Python 文件、Python 依赖或 npm 依赖。

## 配置

默认配置新增以下结构：

```json
{
  "JMComic": {
    "albumIdBlacklist": {
      "enable": false,
      "ids": []
    },
    "authorNameBlacklist": {
      "enable": false,
      "names": []
    }
  }
}
```

`ids` 和 `names` 均为数组。锅巴使用 `GTags` 组件逐项增删，并分别提供启用开关。作者名称黑名单的帮助文案必须说明：启用后每次下载前会额外查询一次本子详情，因此会降低响应速度；`jmv` 当前最多输出前 10 个作者，黑名单只能检查这 10 个名称。

本子 ID 统一按十进制数字字符串处理。命令 ID 和配置 ID 都去除前导零，配置中的数字值与字符串值等价。无效配置项忽略，不影响其他下载。

作者名称去除首尾空白后进行完整匹配，英文不区分大小写。不使用包含匹配或模糊匹配，避免短名称误伤其他作者。

## 下载前检查

检查顺序如下：

1. 检查 JMComic 功能是否启用，并解析消息中的本子 ID。
2. 校验 ID 为纯数字并完成规范化。
3. 如果本子 ID 黑名单已启用，检查规范化后的 ID；命中则回复并结束。
4. 检查 `jmcomic` 命令和消息来源。
5. 同步 JMComic 代理配置。
6. 仅当作者名称黑名单已启用时，执行 `jmv <id> --option="<option.yml>" --yes`。
7. 解析 `jmv` 输出中的作者名称，检查全部可见作者；命中则回复并结束。
8. 两类检查均通过后，才发送准备消息、创建或复制缓存目录并执行 `jmcomic` 下载。

本子 ID 黑名单命中时回复：

```text
JMComic ID: 123 已被加入黑名单，禁止下载
```

作者名称黑名单命中时回复：

```text
JMComic 作者「example」已被加入黑名单，禁止下载
```

## `jmv` 错误处理

作者名称黑名单采用失败关闭策略。启用作者名称黑名单后，出现以下任一情况都停止下载：

- 系统中不存在 `jmv` 命令；
- `jmv` 查询失败或没有输出；
- 输出中找不到可解析的作者字段；
- 命令执行过程中出现其他异常。

用户收到简短、可操作的错误，例如：

```text
JMComic 作者前置检查失败，已停止下载，请检查 jmv 是否可用
```

日志记录本子 ID、失败阶段和脱敏后的错误摘要。日志不记录代理凭据、Cookie 或完整配置文件内容。`jmv` 文本格式变化暂不做多版本兼容；解析失败按上述策略停止下载，后续根据实际版本调整解析器。

作者名称黑名单未启用时不得调用 `jmv`，不会增加网络请求或等待时间。本子 ID 黑名单无论是否启用，都不影响 `jmv` 的调用条件。

## 测试

测试覆盖以下行为：

- 本子 ID 的字符串、数字和前导零规范化；
- 本子 ID 黑名单启用与关闭时的匹配结果；
- `jmv` 单作者、多作者、未知作者和最多 10 名作者的输出解析；
- 作者名称完整匹配、英文大小写和首尾空白处理；
- `jmv` 无输出、命令失败和格式无法识别时停止下载；
- 作者名称黑名单关闭时不执行 `jmv`；
- 默认配置包含两个关闭的黑名单及空数组；
- 锅巴 JMComic 卡片包含两组开关和 `GTags` 数组，并带有性能及数量限制说明；
- README 说明配置结构、检查时机和 `jmv` 限制。

规格、实现与测试分别保持原子提交，不改写现有未推送提交。
